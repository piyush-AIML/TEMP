Metadata, structured data and social previews for the marketing site.

## Metadata

`metadataBase` comes from `NEXT_PUBLIC_SITE_URL`, falling back to `https://educraft.com` — **set the env var for the real domain**. Per-route title / description / canonical.

## Structured data (JSON-LD)

| Schema | Where |
|---|---|
| `EducationalOrganization` | site-wide (`src/app/layout.tsx`) |
| `Course` + `BreadcrumbList` | programme detail pages |
| `Article` | insights articles |

## Social previews

`next/og` `ImageResponse` generates previews for the homepage and per programme, pillar-accented. Sitemap covers all static + SSG routes; `sitemap.xml` and `robots.txt` are generated by `app/sitemap.ts` and `app/robots.ts` — the static `public/robots.txt` was deleted on purpose.

## Satori rule (learned the hard way)

**Every `div` with multiple children inside an OG image must have an explicit `display: 'flex'`,** or the prerender throws.

## Not yet shipped

Insight-article OG images (`insights/[slug]/opengraph-image.tsx`) — the only content type currently missing a social preview (V3 Tier B item 6).
